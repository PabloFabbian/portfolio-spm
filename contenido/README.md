Todo lo que se ve en la web está en esta carpeta. Lo más fácil es cambiarlo desde el editor de la web (`/editar`); estos archivos son los que el editor guarda.

| Qué | Dónde |
| --- | --- |
| Textos de la portada, Sobre mí y Contacto | [`sitio.json`](sitio.json) |
| Textos de cada proyecto | [`proyectos.json`](proyectos.json) |
| Fotos de la portada y de Sobre mí | [`fotos/`](fotos) |
| Fotos y videos de cada proyecto | [`proyectos/`](proyectos), una carpeta por proyecto |
